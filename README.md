EdTech Task Manager – Full Stack Project

A role-based task management system built with:
Frontend: React
Backend: Node.js, Express
Database: MongoDB
Students can manage their own tasks, while teachers can view tasks of students assigned to them.

Features
Teacher:

Can create tasks for themselves
Can view all tasks created by students assigned to them
Can ONLY edit/delete their own tasks
Cannot modify student tasks

Student:
Can create, edit, delete, and update progress of their own tasks
Cannot see tasks of others
Must select their teacher during sign-up

Tech Stack
Backend:
Node.js
Express
MongoDB + Mongoose
JWT Authentication
Bcrypt password hashing

Frontend:
React
Axios
React Router

Project Structure
/server
/client

Backend runs on http://localhost:5000
Frontend runs on http://localhost:3000
